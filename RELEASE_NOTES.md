# v1.0.0

First stable release of the Student Task Manager.

## Added
- Console app to add, show, complete and delete tasks
- Input validation (empty titles, invalid or unknown ids)
- 6 unit tests run by GitHub Actions on push and pull request
- README, user guide and MIT license

## Development process
- Feature work done on `feature/add-task`, `feature/complete-task`,
  `feature/delete-task` and merged with pull requests
- A README merge conflict was created and resolved on purpose
